# SiteNova Connect Deployment Runbook

## Current phase: local development
1. Install Docker Desktop / Docker Engine and Compose v2.
2. Follow INSFORGE_LOCAL_SETUP.md.
3. Confirm InsForge is healthy and its dashboard opens locally.
4. Configure the app's local .env from .env.example using only credentials generated by this isolated InsForge instance.
5. Run npm install, npm run check, then npm run dev.
6. Verify /api/health and /api/config.
7. Do not import WACRM customer data or activate WhatsApp webhooks until schema, auth and tenant-isolation tests pass.

## Production is not enabled
Before production: provision a dedicated host; pin InsForge image/release; set public HTTPS URLs; configure reverse proxy and firewall; use persistent storage and off-host encrypted backups; configure SMTP and object storage; protect admin endpoints; set monitoring/logging; test restore and rollback. Never publish database, PostgREST or internal auth ports.

## Data safety
The two existing managed Supabase projects are not migration targets. Do not connect to them, run SQL against them, change settings, or use their credentials. Original WACRM source repository is also read-only.
